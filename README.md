1. Что нужно для реализации:
 - Компьютер с debian
 - Плата Arduino Nano
 - Плата ESP 8266
 - Принадлежности для пайки.

2. План сборки:
 a. Установить прошивку на Arduino Nano (см. hardware/arduino_nano_terrace_climate.ino) и на ESP 8266 (см. hardware/ESP8266_terrace_climate.ino). Прошить ESP 8266 можно через Arduino IDE - искать инструкцию в сети. Перед прошивкой ESP поправить имя и пароль точки доступа WiFi.
 b. Макетировать плату, проверить, что Arduino Nano собирает информацию с датчика влажности/температуры, ESP 8266 собирает данные с Arduino и выдает их на веб-сервер.
 c. Спаять плату и собрать в корпус метеостанцию. Принципиальную схему и схему травления см. в каталоге "hardware/EasyEDA_TerraceClimate/"
 d. Развернуть на компе с debian сборщик данных и веб-интерфейс, зарегистрировать сервисы для компонентов проекта (см. каталог /deploy и файл /deploy/setup_order_on_linux)
